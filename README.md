## What I learned

- **CNNs:** building the layers, writing DataLoaders and training loops by hand in PyTorch.
- **Transformers:** tokenization, fine-tuning a pretrained model with the HuggingFace Trainer API.
- **Shipping:** wrapping each model in a Streamlit app and publishing it.
